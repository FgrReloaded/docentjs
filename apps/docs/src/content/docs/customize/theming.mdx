## Tokens

Theme tokens are part of the tour JSON, so a builder can set them and they travel with the tour.

```ts
options: {
  theme: { accent: '#7c3aed', radius: '14px', width: '340px', overlayOpacity: '0.7' },
}
```

Each token becomes a `--docent-*` custom property on the shadow host: `background`, `foreground`, `muted`, `accent`, `accentForeground`, `radius`, `shadow`, `font`, `width`, `overlay`, `overlayOpacity`, `duration`, `zIndex`.

Layers apply lowest to highest: renderer `theme`, then the template's theme, then the tour's `options.theme`.

## Presets

```ts
import { dark, minimal, contrast } from '@docentjs/dom/themes'
createTour(tour, { renderer: { theme: minimal } })
```

The presets ship from a separate entry so they cost nothing unless imported. The default theme follows `prefers-color-scheme`.

## CSS parts

For anything tokens do not cover, style parts from your own stylesheet. Parts: `overlay`, `popover`, `arrow`, `header`, `title`, `close`, `body`, `media`, `footer`, `progress`, `buttons`, `button`, `button-next`, `button-back`, `button-skip`.

```css
[data-docent-host]::part(title) { text-transform: uppercase; letter-spacing: 0.04em; }
[data-docent-host]::part(button-next) { border-radius: 999px; }
```

Or inject CSS into the shadow root with the renderer's `css` option or a template's `css`.
