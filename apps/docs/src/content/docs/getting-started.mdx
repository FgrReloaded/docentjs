`@docentjs/dom` is the web renderer and depends on `@docentjs/core`, the platform-agnostic engine. The framework packages depend on both.

## Define a tour

A tour is a plain JSON-compatible object. `defineTour` gives you type inference and stamps the schema version.

```ts
import { createTour, defineTour } from '@docentjs/dom'

const tour = defineTour({
  id: 'welcome',
  version: 1,
  options: { showProgress: true },
  steps: [
    { id: 'intro', title: 'Welcome', body: 'This takes about a minute.' },
    { id: 'sidebar', target: { name: 'sidebar' }, title: 'Navigation', placement: 'right' },
    { id: 'new', target: '#new-project', title: 'Create a project', advance: { on: 'click' } },
    { id: 'done', title: 'All set' },
  ],
})
```

## Mark targets

Prefer a logical name over a CSS selector. It survives refactors and works on native platforms later.

```html
<aside data-docent="sidebar">…</aside>
```

A bare string target such as `'#new-project'` is treated as a CSS selector.

## Start it

```ts
const controller = createTour(tour)
controller.start()
```

`createTour` wires the web renderer, `localStorage` persistence, and route tracking. Call `resume()` instead of `start()` to continue where the user left off.
